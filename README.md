# BWP Sales — ระบบจัดการงานขาย

เว็บแอปจัดการงานขายของ **บริษัท เบสท์เวิลด์ อินเตอร์พลาส จำกัด (BWP)**
ทั้งระบบอยู่ในไฟล์เดียว (`index.html`) ไม่ต้อง build ไม่ต้องติดตั้งอะไร

## หน้าจอในระบบ

| หน้า | ใช้ทำอะไร |
|---|---|
| หน้าแรก (Dashboard) | ยอดขาย ยอดในมือ กราฟรายเดือน Pipeline — กดเจาะดูรายการได้ทุกจุด |
| ลูกค้าติดต่อเข้ามา | รายชื่อลูกค้า สถานะ และไทม์ไลน์ว่าดำเนินการถึงไหน |
| เอกสารการขาย | ใบเสนอราคา · ใบขอตัวอย่าง · ใบข้อกำหนดของลูกค้า · ใบขอเครดิต |
| PO ลูกค้า | รายการสินค้า คิด VAT และแนบรูป/ไฟล์ PO |
| ใบเสร็จรับเงิน | ออกใบเสร็จ ติดตามการชำระเงิน |
| ข้อมูลลูกค้า | ข้อมูลบริษัท ประวัติการซื้อ อัปโหลดโลโก้/รูป/เอกสาร |

## สูตรยอดขาย

ยอดขายรับรู้จาก **ใบเสร็จรับเงิน** เท่านั้น จึงไม่นับซ้ำกับ PO
งานที่ปิดการขายแล้วแต่ยังไม่ออกใบเสร็จ (รวมเคสลูกค้าที่ซื้อโดยไม่มี PO มีแค่ใบเสนอราคา)
จะไปอยู่ในการ์ด **"ยอดในมือ"** พร้อมปุ่มออกใบเสร็จในคลิกเดียว

## ใบเสนอราคาและการเซ็นอนุมัติ

- พิมพ์ตามแบบฟอร์มบริษัท A4 (FQP-MKT-01:01 Rev.02)
- เซ็นบนหน้าจอได้ทั้งเมาส์ ปากกา (Apple Pencil ไล่น้ำหนักเส้นตามแรงกด) และนิ้ว
- ฝ่ายขายเซ็น → ส่งลิงก์ให้ผู้บริหาร → ผู้บริหารเซ็นบนมือถือ/iPad → ลายเซ็นเด้งกลับเข้าระบบอัตโนมัติ

## การเก็บข้อมูล

- ข้อมูลงานขายเก็บใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง
- มีเฉพาะ **คำขออนุมัติใบเสนอราคา** ที่เก็บบน Supabase เพื่อให้ลิงก์เซ็นทำงานข้ามเครื่องได้

### ติดตั้งฐานข้อมูล (ทำครั้งเดียว)

เปิด Supabase → SQL Editor → รันไฟล์ [`supabase-setup.sql`](supabase-setup.sql)

ตารางเปิด RLS โดยไม่มี policy ใด ๆ — เข้าถึงได้เฉพาะผ่าน 3 ฟังก์ชันที่ต้องรู้ UUID ของเอกสารนั้น
จึงดึงรายการเอกสารทั้งหมดออกไปไม่ได้ และเซ็นซ้ำเพื่อแก้ผลอนุมัติทีหลังไม่ได้

เปลี่ยน URL / key ได้จากปุ่ม **"ตั้งค่าฐานข้อมูล"** ที่เมนูซ้าย

## พัฒนา / แก้ไข

แก้ `index.html` ไฟล์เดียว แล้วเปิดในเบราว์เซอร์ได้เลย ไม่ต้อง build
